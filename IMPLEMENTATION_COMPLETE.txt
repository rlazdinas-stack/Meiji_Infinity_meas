ALGORITHMS:
----------
Edge Detection:
  - Gaussian blur (5x5 kernel)
  - Canny edge detector (configurable thresholds)

Subpixel Refinement:
  - Row-by-row intensity gradient analysis
  - Maximum gradient detection
  - Parabolic interpolation for subpixel accuracy

Line Width Measurement:
  - Edge pairing by horizontal position
  - Per-row width calculation
  - Statistical analysis (mean, std dev, min, max)
  - Minimum 3 samples required per line
